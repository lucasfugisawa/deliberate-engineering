# Capture practice into overrides

Invoke the `deliberate-engineering-capture` skill.

$ARGUMENTS

Observe this session for deviations (a deliberate-engineering lens, composition pattern or rule was applicable and you corrected, skipped, or contradicted it), recurring patterns the catalog lacks, and calibration adjustments (for a recognizable class of work, you repeatedly ran a ceremony depth different from the plugin's recommendation). Map each to an addressable override target and operation, show the exact block that would be appended, and, only on your approval, append it to `~/.claude/deliberate-engineering/overrides.md`. Recommend, never force. If nothing is worth an override, say so and write nothing.
